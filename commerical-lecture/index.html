数据加载失败

页面文案存于 web_data/content.json，经 fetch() 加载，直接双击打开会被浏览器拦截。请在模板目录启动本地服务器：

cd html-templates/commerical-lecture && python -m http.server 8080

然后访问 http://localhost:8080（或改用 Edge / Firefox 直接打开 index.html）。
