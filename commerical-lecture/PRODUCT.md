# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

静态 HTML + 素材目录（用户选定）：`index.html` + `assets/` + `web_data/`，无构建工具、无外部 CDN 依赖，双击 `file://` 即可离线演示。沿用仓库 `html-templates/lab-meeting/` 的目录惯例（数据驱动 + schema.md 文档）。

## Users

- **汇报人（用户本人）**：科研工作者，在向潜在合作方演示的现场操作页面（鼠标 / 键盘 / 翻页笔）。
- **观众**：华为等甲方公司的评审人员，正在洽谈下一阶段合作，对"用 AI 做产品"的能力感兴趣。判定标准：页面能否在数分钟内让人相信汇报方的 AI 使用能力。

## Product Purpose

一个商业汇报演示网页模板，用于展示个人 AI / Agent 学习经验与 AI 制作的项目。以三条叙事线展开：个人科研开展 → 团队科研协作 → 个人与团队科研如何建立联系；每条线容纳 1-2 个 skill 的介绍、其产出的产品、以及该 skill 的构建过程。成功 = 甲方看完后认为汇报方具备真实、系统化的 AI 使用能力。

## Positioning

三条叙事线的递进结构（个人 → 团队 → 联结）本身就是能力证据的编排方式——不是罗列工具，而是展示能力如何在科研组织里生长、复制与协作。页面形态为混合式：开场长滚动叙事 → 三章翻页节奏（每章一个 slide deck）→ 汇流收尾，兼顾网页叙事感与 PPT 式演示节奏。

## Operating Context

- 现场演示场景：投影 / 大屏，操作方式为鼠标滚轮、键盘方向键、翻页笔（PageDown）。
- 页面需要离线可用（拷贝即演示），故不依赖 CDN 字体、外部脚本。
- 内容技能不在本项目中——本任务只交付模板，全部正文内容为占位符，后续由用户填充真实 skill 与产出。

## Capabilities and Constraints

- 混合式交互：开场段落自然滚动；三章各为一个全屏 slide deck，滚轮 / 键盘 / 翻页笔驱动翻页，末页后回到自然滚动进入下一章；收尾回归自然滚动。
- 数据驱动：全部文案、章节、skill 占位内容存于 `web_data/content.json`，改数据即改页面，无需动 HTML。
- 设计约束（用户明确）：模板不得有"AI 味"（规避 AI 初创公司式渐变 / 极简套路），但页面必须融入 AI 元素（小图标、背景设计）。
- 中文排版规范：系统字体栈、暗色页正文 `rgba(255,255,255,.85)`、对比度 ≥ 7:1、禁负字距、行高 ≥ 1.5。
- 视觉世界（用户选定四系统合并）：Linear 暗色基底 + Superhuman twilight 渐变与光晕（AI 元素）+ Stripe 排版气质 + IBM 信息架构。
- 待定（用户后续填充）：三条线各自的真实 skill 清单、产出截图、汇报人署名、真实数据指标。

## Brand Commitments

无既有品牌资产。页面主标题、汇报人署名、课题组名称均为占位符（用户选定占位策略，交稿后自行替换）。

## Evidence on Hand

仓库内已有真实产出可作为未来填充素材（`html-templates/lab-meeting/`、mediawiki 输出、LVEF 标注等），但本次交付**不引用**这些内容——用户明确其要讲的 skill 不在本项目中，页面内容全部为占位符。占位符不得伪装成真实内容；产出展示位使用明确标注的占位框。

## Product Principles

1. 叙事先行：页面结构服务于"三条线一个终点"的能力叙事，不是组件陈列。
2. 占位诚实：所有待填内容清晰可辨、结构完整，替换成本最低（改一个 JSON）。
3. 演示即体验：交互为现场演示优化（翻页笔、键盘、滚轮全覆盖），离线可用。
4. 克制的高级感：深色暗场 + 单一薰衣草紫 accent，AI 元素收敛为一个 signature（叙事轴脉冲光点），不堆砌。
5. 数据与视图分离：文案数据驱动，模板可复用于不同汇报主题。

## Accessibility & Inclusion

- 遵循 `prefers-reduced-motion`（弱化位移与自动动画，保留透明度变化）。
- 键盘可完整操作（翻页 / 跳章）。
- 中文正文 ≥ 14px，行高 ≥ 1.5，暗色页对比度 ≥ 7:1。
