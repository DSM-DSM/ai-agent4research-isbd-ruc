📋 论文概览

Takeaway 🎯 MDS-ED = 急诊多模态（ECG + 表格）→ 1428 个 ICD 标签的公开 benchmark，立框架、给基线。

论文：Enhancing Clinical Decision Support with Physiological Waveforms — A Multimodal Benchmark in Emergency Care（Lopez Alcaraz, Bouma, Strodthoff, Univ. Oldenburg）——提出 MDS-ED 基准：急诊场景多模态 ICD 诊断编码（1428 个 ICD-10-CM）+患者恶化（15 指标）预测；模态=12 导联 ECG@100Hz（S4 编码）+470 维表格特征（3 层 MLP）+临床文本（本实验配置未启用）；129,057 样本/71,098 患者（MIMIC-IV-ED）；论文声称多模态 macro-AUROC 0.8334 [0.8300, 0.8366]。

🏗️ 模型架构 (S4 + MLP + Concat Fusion)

Takeaway 🎯 骨架 = S4 时序编码器 + MLP 静态编码器 + Concat 融合 + 线性预测头——后续所有改进只动 head 与 loss。

📊 关键发现：introduce_nan_columns 对AUROC的显著影响
⚠️ 重要
🔬 发现时间：2026年6月23日
问题描述： MDS-ED数据集中某些tabular列存在于训练集但完全缺失于验证/测试集（如某些实验室检验项目仅对特定病人群体做）。introduce_nan_columns=True 时显式引入NaN列让模型感知缺失模式 → 训练更鲁棒。
配置 introduce_nan_columns input_channels_cont 验证集 macro-AUROC (agg0) 测试集 macro-AUROC (agg1) Δ val Δ test
Baseline (原始) False 463 0.8187 0.8270 — —
Baseline w/ NaN Mask True 926 0.8264 0.8356 +0.0077 +0.0086
⚠️ 影响： 方法1和方法2的所有实验均在 introduce_nan_columns=False 下运行，需要在 True 下重新运行以获得公平对比。（对比时应使用 0.8264 而非 0.8187 作为baseline）

Takeaway 🎯 显式引入 NaN 指示列显著提升 AUROC——「哪里缺失」本身就是强特征（后续 M20 三源复现 +0.86pp）。

📐 关键数学公式

Takeaway 🎯 核心公式汇总：BCE 主项 + 层级约束 + 链式法则——MDS-ED 及其三个改进方向的数学基础。

1. Binary Cross Entropy Loss (多标签基础损失)
\[ \Lcal_{\bce} = -\frac{1}{N}\sum_{i=1}^{N}\sum_{j=1}^{C} \Bigl[ y_{ij} \log\sigma(\hat{y}_{ij}) + (1-y_{ij})\log\bigl(1-\sigma(\hat{y}_{ij})\bigr) \Bigr] \] 其中 \(C=1428\) 为ICD编码总数，\(\sigma(x)=1/(1+e^{-x})\) 为sigmoid函数，\(\hat{y}_{ij}\) 为模型输出logits
2. Focal BCE Loss (处理类别不平衡)
\[ \Lcal_{\fbce} = -\frac{1}{N}\sum_{i=1}^{N}\sum_{j=1}^{C} (1-p_{t,ij})^{\gamma} \cdot \bce(y_{ij}, \hat{y}_{ij}) \] \[ p_{t,ij} = \sigma(\hat{y}_{ij})\cdot y_{ij} + \bigl(1-\sigma(\hat{y}_{ij})\bigr)\cdot(1-y_{ij}) \] \(\gamma=2\) 降低易分样本权重，聚焦难分样本。\(p_{t,ij}\) 为"真实类别置信度"
3. Macro-AUROC (主评估指标，Bootstrap N=1000)
\[ \AUROC_{\mathrm{macro}} = \frac{1}{C}\sum_{j=1}^{C}\AUROC_j = \frac{1}{C}\sum_{j=1}^{C}\int_{0}^{1}\TPR_j\bigl(\FPR_j^{-1}(t)\bigr)\,dt \] 对每个ICD编码独立计算AUROC后取平均。论文还报告micro-AUROC和95% Bootstrap置信区间
4. S4 结构化状态空间模型 (Waveform Encoder)
\[ \begin{aligned} \dot{x}(t) &= \mathbf{A}\,x(t) + \mathbf{B}\,u(t) \\ y(t) &= \mathbf{C}\,x(t) + \mathbf{D}\,u(t) \end{aligned} \] HiPPO矩阵初始化 \(\mathbf{A}\)，通过结构化卷积核加速长序列建模。配置：4层S4, state_dim=8, model_dim=512
5. 多模态融合 (Concat Fusion)
\[ \mathbf{h}_{\mathrm{fused}} = \bigl[\,\mathbf{h}_{\mathrm{waveform}} \;\|\; \mathbf{h}_{\mathrm{tabular}}\,\bigr] \] \[ \hat{\mathbf{y}} = \sigma\bigl(\mathbf{W}_{\mathrm{out}}\,\mathbf{h}_{\mathrm{fused}} + \mathbf{b}_{\mathrm{out}}\bigr) \in [0,1]^{1428} \] S4编码器输出(512维) + 3层MLP编码器输出 → 拼接 → 线性分类头(1428维) → Sigmoid
