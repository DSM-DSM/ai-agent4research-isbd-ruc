💡 关键发现

Takeaway 🎯 五条关键发现：后处理清 VR 最优、MC loss 恶化、tree_min 有效但伤 AUROC、flat 系列不建议——推荐路径 = HBCE + roll 后处理。

  1. HBCE+rolldown 全局最优：test 0.8370（vs baseline 0.8338，+0.0032），VR=0。
  2. roll 后处理近乎无损清零 VR：baseline/HBCE 的 AUROC Δ ≤ 0.0001。
  3. MC Loss 适得其反：VR 11.74→20.94%、AUROC −0.0142（rollup 仅部分恢复）。
  4. tree_min_loss 降 VR 至 1.2% 但损 AUROC ~0.009。
  5. flat 系列训练时 VR=0 但 AUROC −0.009~−0.011——用后处理替代训练时约束。
📐 建议：推荐 HBCE + roll 后处理（同得 AUROC 提升与 VR=0）；不建议 MC loss / flat 系列；可探索 tree_min 调 weight、roll 作为通用后处理。

🔍 层次违反率 (VR) 汇总
📐 VR 计算公式： \[ \mathrm{VR} = \frac{1}{N \cdot |\mathcal{P}|} \sum_{i=1}^{N} \sum_{(p,c) \in \mathcal{P}} \mathbf{1}\bigl\{\sigma(\hat{y}_c^{(i)}) > \sigma(\hat{y}_p^{(i)})\bigr\} \] N = 25,756 样本, |P| = 978 父子标签对, σ(·) = sigmoid 输出概率。
对每个样本的每对父子标签，统计子标签预测概率严格大于父标签的比例。 该指标衡量模型预测违反"父 ≥ 子"层次约束的程度。

📐 对各研究方向的影响

Takeaway 🎯 方向二的 Gap 不影响 HBCE 惩罚、但会影响 HMLC 条件概率训练的精度（约 5.6% 低估）。

方向HBCE（损失惩罚）HMLC（条件概率训练）
方向一（子→父 0 违反） data-driven 权重恒为零（P(child=1|¬parent)≡0）→ 已改用 fixed β=1 条件掩码 1{z_a(m)=1} 天然正确——子阳时父必阳
方向二（父→子 5.6% Gap） 不影响——HBCE 仅约束 σ(child)≤σ(parent)，不依赖"父阳→子阳" Stage1 条件概率 p(child=1|parent=1) 被低估约 5.6%——父阳样本中所有已知子阴的情况存在
📌 结论：① 子→父 0 违反（前缀闭包正确；亦解释 HBCE data-driven 权重恒为零）；② 父→子 5.6% Gap，集中仅 1 子节点的父标签（均值 16.24%，临床上=Undefined 子类/标签体系不完整）；③ baseline 从完美一致数据学出 11.74% 违反 = BCE 无层级约束梯度；④ Gap 不影响 HBCE、但低估 HMLC 条件概率 ~5.6%。
